# Clairveil 로컬 reference

Linux/WSL2, Go 1.25.13에서 [LOCAL_RUN.md](LOCAL_RUN.md)를 사용합니다. 고정 SHA: af04cfc994a3da87a8b1b902eda0988feb512539. 원본 코드 수정 없이 실행했고 Apache-2.0 원본 라이선스를 유지합니다.

실제 node deposit→transfer→scan, 독립 초기 상태 재현이 완료됐습니다. Windows native 실행 실패는 과거 환경 기록이며 현재 Linux 성공과 구분합니다. 개발용 artifacts를 사용하며 Maroo verifier 호환성을 보장하지 않습니다. uclair는 로컬 실습 자산입니다.

소스·빌드·아티팩트 생성은 사전 준비입니다. 실행 증거와 경계는 [Privacy 검증](../../docs/PRIVACY_VALIDATION.md)을 참고합니다. 원시 keys/notes/logs는 공개하지 않습니다.
