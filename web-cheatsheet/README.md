# 실습 커맨드 웹사이트

[배포 사이트](https://maroo-workshop-cheatsheet.zcb167.chatgpt.site)

한 페이지에 환경 준비, PCL·EAS, 독립 로컬 Privacy, 성공 기준, 체험·공식 참고자료를 담았습니다. 8개 명령 블록을 복사할 수 있습니다. 서버로 키를 보내거나 브라우저에서 거래를 전송하지 않습니다.

현재 접근 범위: **private**. 참가자 공개 여부는 사이트 접근 설정을 따릅니다.

이 폴더는 배포 소스의 공개 사본입니다. Sites가 실제 배포와 접근 범위를 관리합니다. 로컬에서는 이 폴더를 정적 웹서버로 열 수 있습니다. 파일을 직접 열 때 Clipboard API가 제한되면 선택 후 수동 복사를 안내합니다.

체험 링크는 https://experience.maroo.io/ko 이며 사용자가 진행한 경로는 시뮬레이션입니다. 실제 EAS 발급·트랜잭션 검증용으로 안내하지 않습니다.
