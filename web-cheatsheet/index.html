환경계정PCL · EASPrivacy

1. 실행 환경

PowerShell은 Bash 명령·경로 처리와 호환되지 않아 제외합니다. Windows에서는 WSL2의 Linux 터미널을 사용하세요.

01

프로젝트 준비

git clone https://github.com/nubro999/maroo-devrel-workshop.git
cd maroo-devrel-workshop
npm ci
npm run setup

이후 모든 명령은 이 폴더에서 실행하세요.

2. 내 계정 불러오기

진행자에게 받은 participant-N.json을 선택하세요. 파일은 이 브라우저 안에서만 읽습니다.

아직 선택한 계정이 없습니다.

지급자
수취인

받은 .env를 프로젝트 폴더의 .env와 교체하세요. 개인키가 포함되어 있으니 본인 파일만 사용하고 공유하지 마세요.

3. 정책으로 지급 통제하기

Maroo 테스트넷에서 실행합니다. 테스트 토큰이 사용됩니다.

02

연결 확인

npm run check:rpc
npm run balance

chain ID 450815와 지급자 잔액을 확인하세요.

03

지급 허용·차단

node demo/pcl/run.mjs --broadcast

성공: recipientDelta가 양수. 차단: status 0, recipientDelta 0, 지급 횟수 유지.

04

자격 발급·폐기

node demo/pcl/eas-run.mjs --broadcast

자격 없음: 실패 → 발급·인덱싱: 성공 → 폐기: 실패. 03번 성공 후 실행하세요.

이미 실행한 실습을 다시 하려면

기존 실행 결과는 덮어쓰지 않습니다. 실행 폴더 보관 안내를 확인하세요.

4. 비공개 지급 실행하기

macOS와 Linux 모두 같은 Docker 명령을 사용합니다. 별도 로컬 체인에서 Alice 10 → Bob 7 → 잔액 3 / 7을 확인합니다.

Docker에 메모리 8GB 이상을 배정하세요. macOS 실기기 전체 실행은 아직 검증하지 않았습니다.

05

Privacy 환경 만들기

docker build -t maroo-privacy-lab -f demo/clairveil/container/Dockerfile demo/clairveil

처음 한 번 실행합니다. Docker가 실행 중이어야 합니다.

06

비공개 지급 실행

mkdir -p .private/privacy-container
docker run --rm --init -e LAB_UID="$(id -u)" -e LAB_GID="$(id -g)" \
  --mount type=volume,source=maroo-privacy-cache,target=/cache \
  --mount "type=bind,source=$PWD/.private/privacy-container,target=/results" \
  maroo-privacy-lab

처음에는 빌드·증명 자료 생성에 시간이 걸립니다. 창을 닫지 말고 PASS를 기다리세요.

07

결과 확인

cat .private/privacy-container/PUBLIC_RESULT.json

result: PASS · Alice 3 · Bob 7 · repeatScanStable: true

다시 실행할 때는 06번부터 진행하세요. 캐시를 재사용하고 새 계정·체인으로 시작합니다.
