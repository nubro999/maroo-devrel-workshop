01 환경 준비

01. 설치

준비·조회
git clone https://github.com/nubro999/maroo-devrel-workshop.git
cd maroo-devrel-workshop
npm ci
npm run setup

Node 22.14 또는 24 · Git. 로컬 Privacy는 Linux/WSL2가 필요합니다. 이미 저장소가 있다면 해당 폴더에서 시작하세요.

로컬 .env를 먼저 작성하세요.

MAROO_PRIVATE_KEY는 테스트 전용 키, MAROO_ADDRESS는 그 키의 공개 주소, MAROO_RECIPIENT는 다른 수신자 주소입니다. 키는 터미널 명령이나 이 웹사이트에 붙여넣지 않습니다. 브라우저는 지갑을 연결하지 않습니다.

환경 설정 안내 ↗

준비·조회
npm run check:rpc

chain ID 450815, 테스트 잔액과 공개 정책 조회를 확인합니다. privacy:public의 PASS는 Privacy 지급 성공을 뜻하지 않습니다.

02 PCL · EAS

같은 지급 요청을 정책과 자격 상태만 바꿔 비교합니다.

03. 프록시 지급 허용·차단

테스트넷 전송
node demo/pcl/run.mjs --broadcast

전용 프록시를 배포하고 0.001 tOKRW를 지급합니다. 이어서 송신자를 차단한 뒤 같은 요청이 거절되는지 확인하고 정책을 복원합니다.

04. EAS 자격 수명주기

테스트넷 전송
node demo/pcl/eas-run.mjs --broadcast

03번 성공 후 실행. 자격 없음 status 0 → 발급·인덱싱 후 status 1 → 폐기 후 status 0. 자체 발급 데모이며 실제 KYB가 아닙니다.

05. 선택 실험: false / true

테스트넷 전송
node demo/pcl/eas-boolean.mjs --broadcast

03번에서 만든 프록시를 사용합니다. 기존 실제 실험에서는 false와 true 모두 지급 통과. 이번 EAS_POLICY가 bool true를 강제하지 않았습니다.

전송 전 확인

각 실험은 실제 테스트넷 수수료를 사용합니다. 관찰 수수료는 약 18–28 tOKRW였고 실행별 상한은 100 tOKRW입니다. 지급액은 별도입니다. 실패 거래도 수수료가 발생합니다. 명령은 한 번씩 순서대로 실행하세요.

결과: .private/pcl-proxy/RESULT.json, .private/eas-privacy-run/EAS_RESULT.json, .private/eas-boolean-run/EAS_RESULT.json. 기존 폴더를 덮어쓰지 않습니다. 재실행은 보관·복구 안내를 확인하세요.

03 로컬 Privacy

Maroo 실습과 독립된 환경입니다. 예치 10 → Bob에게 7 → Alice 3 / Bob 7.

06. 사전 준비 + 첫 실행

로컬 실행
SUBMISSION_DIR="$PWD"
RUN_PARENT=$(mktemp -d /tmp/maroo-workshop.XXXXXX)
export GOPATH="$RUN_PARENT/go"
export GOCACHE="$RUN_PARENT/go-build-cache"
git -c core.autocrlf=false clone https://github.com/DELIGHT-LABS/clairveil.git "$RUN_PARENT/source"
git -C "$RUN_PARENT/source" checkout --detach af04cfc994a3da87a8b1b902eda0988feb512539
GOTOOLCHAIN=go1.25.13 python3 "$SUBMISSION_DIR/demo/clairveil/run-local.py" \
  --source "$RUN_PARENT/source" \
  --run-dir "$RUN_PARENT/run"

제출 저장소 루트에서, 같은 터미널로 실행합니다. Linux/WSL2 · Python 3 · Go 필요. 첫 빌드·개발용 회로 생성은 수업 전 완료하세요. 약 6GiB RAM + 2GiB swap 환경에서 검증했으며 장비별 시간은 다릅니다.

07. 공개 결과 확인

로컬 실행
python3 -m json.tool "$RUN_PARENT/run/PUBLIC_RESULT.json"

06번을 실행한 같은 터미널에서 확인합니다. 포함 거래 code 0, Alice 3 / Bob 7, 반복 scan 안정 여부를 봅니다. PUBLIC_RESULT만 공유하고 원시 키·note·로그는 공개하지 않습니다.

08. 수업 중 재실행 · 캐시 재사용

로컬 실행
REPEAT_PARENT=$(mktemp -d /tmp/maroo-repeat.XXXXXX)
GOTOOLCHAIN=go1.25.13 python3 "$SUBMISSION_DIR/demo/clairveil/run-local.py" \
  --source "$RUN_PARENT/source" \
  --artifacts "$RUN_PARENT/run/artifacts" \
  --run-dir "$REPEAT_PARENT/run"
python3 -m json.tool "$REPEAT_PARENT/run/PUBLIC_RESULT.json"

06번 첫 실행에 성공한 같은 터미널에서 실행합니다. 06번의 GOPATH·GOCACHE 설정과 증명 자료를 유지하고, 계정과 체인 초기 상태는 새로 만듭니다. 다른 터미널로 바꿨다면 먼저 같은 캐시 경로를 설정하세요. 원본 실행 폴더를 삭제하지 않습니다.

사전 artifacts 재사용과 새 초기 상태 재현은 로컬 실행 가이드 ↗를 따르세요. 로컬 uclair는 tOKRW와 다른 자산입니다. 이 결과가 Maroo Privacy 호환성·감사자 복호화를 증명하지는 않습니다.

실패했는데 가스비가 나왔나요?

정책 검사를 거쳐 블록에 포함된 실패 거래도 수수료를 냅니다. 사용자 실습에서는 수취인 증가량이 0이었고, 실패 거래 수수료는 2.25 tOKRW였습니다. 지급액 0.001 tOKRW는 전달되지 않았습니다.

Gwei는 화면에 표시된 가격 단위입니다. ETH로 결제했다는 뜻은 아닙니다. 이번 수수료는 tOKRW로 확인합니다. 전송 전 시뮬레이션에는 온체인 수수료가 없지만, 이 데모는 실패 영수증을 확인하려고 실제 전송합니다.
