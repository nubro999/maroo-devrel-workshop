# 디자인 — White × Maroo

워크숍 10장과 영상용 7장, 실습 웹사이트의 시각 체계를 맞췄습니다. Canva에서 볼 수 있는 프레젠테이션 구성을 참고한 편집용 PPTX이며, Canva 안에서 만든 문서는 아닙니다.

- 기본 배경: White `#FFFFFF`
- 핵심 강조: Maroo Teal `#0096AA`
- 보조 강조: Orange `#FF8C50`
- 작은 글자와 링크: Deep Teal `#007A8A`
- 본문: `#16343B` / 보조 문장: `#5C747B`
- 밝은 도식 바탕: `#EAF7F9` / 강조 바탕: `#FFF1E8`

청록·주황 원색은 [Maroo 공식 사이트](https://www.maroo.io/en)의 CSS 변수(--teal, --orange)를 확인해 사용했습니다. 공식 브랜드 가이드 전체를 확보했다는 뜻은 아닙니다. 주황색 작은 글자는 가독성을 위해 더 진한 색을 사용합니다.

표지는 큰 제목과 두 실습 카드, 아키텍처는 연결 도식, 자격 비교는 열린 3열, Privacy 결과는 큰 숫자로 구분했습니다. 슬라이드마다 같은 카드 틀을 반복하지 않습니다. 총 10장, 70분 구성, 참고 링크와 대본은 유지했습니다.

PPTX의 글자와 도형을 편집할 수 있습니다. 다른 편집기에서 열 때 글꼴·줄바꿈은 PDF와 비교해 확인하세요.
