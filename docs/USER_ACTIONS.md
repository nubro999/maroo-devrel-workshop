2. **실습 리허설:** SETUP과 demo/pcl, LOCAL_RUN을 따라 필요한 구간을 직접 확인합니다. 이미 관찰한 단계와 본인이 직접 실행한 단계를 구분합니다. 전체 70분 참가자 리허설은 아직 미완료입니다.
3. **5–8분 영상 녹화:** VIDEO_SCRIPT와 video 슬라이드, 실제 Explorer·JSON·코드를 사용합니다. 전체 70분을 녹화할 필요는 없습니다. 키·개인정보 화면을 제외합니다.
4. **업로드·URL 등록:** 공개/일부 공개 링크와 실제 길이·녹화 commit을 video-link.md에 적습니다. 비로그인 창에서 접근을 확인합니다.
