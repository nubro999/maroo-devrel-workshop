# 제출 영상 — 7분 목표 / 한국어

5–8분 요구사항에 맞춘 촬영 대본입니다. 아래는 실제 발화용 초안이며 본인의 말투로 리허설하세요. 새 거래를 실시간 전송하지 않아도 저장된 실제 기록과 Explorer를 보여줄 수 있습니다. 이 경우 '이전에 실행한 거래'라고 말합니다. 영상 링크·실제 길이는 녹화 후 등록합니다.

## 0:00–0:50 / 대상과 문제

화면: VIDEO_SLIDES 1장, 저장소 README.

“이 워크숍은 기업 지급 업무를 온체인으로 확장하는 은행·핀테크 엔지니어를 대상으로 합니다. 기존 은행 시스템에서 심사한 자격을 실제 지급 실행에도 적용할 수 있는지 검증합니다. Track B로, Maroo 지급 통제와 Clairveil 비공개 지급을 두 실습으로 나눴습니다. 두 결과를 하나의 Maroo 비공개 지급 성공으로 합치지는 않았습니다.”

## 0:50–1:40 / 구조와 책임

화면: 구조 슬라이드, demo/pcl README.

“은행의 심사는 체인 밖에 있습니다. EAS는 자격을 기록하고, PCL은 설정된 조건을 실행 시 검사합니다. 참가자는 자신이 배포한 PCL 프록시에 정책을 붙입니다. 전역 정책 관리자가 되는 실습은 아닙니다. 지급 요청은 프록시로 보내며, 프록시가 정책 검사와 지급 로직을 연결합니다.”

## 1:40–2:50 / 실제 PCL·EAS 결과

화면: EAS_LIFECYCLE_VERIFIED.json과 성공·폐기 실패 Explorer 탭.

“여기는 실제 테스트넷에서 실행한 기록입니다. 증명이 없으면 EasNoAttestationReceived로 거절됐습니다. 데모 증명을 발급하고 인덱서에 등록한 뒤에는 0.001 tOKRW 지급이 성공했고 PolicyCheckPassed가 나왔습니다. 증명을 폐기한 뒤 동일한 요청은 EasAttestationRevoked로 실패했습니다. 해시만 보지 않고 영수증과 수신자 잔액, 지급 횟수를 대조했습니다. 자격 발급만으로 인덱싱이 자동 완료되지는 않아 별도 등록이 필요했습니다.”

## 2:50–3:40 / 승인 취소 후 차단 확인

화면: EAS_LIFECYCLE_VERIFIED.json의 revoked-credential-broadcast와 실패 거래.

“핵심은 승인 취소가 다음 지급에 반영되는가입니다. 기존 증명을 폐기하고 같은 지급을 요청하자 status 0으로 거절됐고, 수취인 잔액은 늘지 않았습니다. 따라서 이 실습에서는 자격 없음, 유효한 자격, 폐기된 자격을 각각 미승인, 승인, 승인 취소로 표현합니다. 증명 안의 bool을 검사하는 데모는 아닙니다. 실제 은행에 적용하려면 신뢰할 발급자만 증명을 발급하도록 통제해야 합니다.”

## 3:40–4:55 / Privacy 별도 흐름

화면: LOCAL_RUN.md, LOCAL_PRIVACY_LIFECYCLE.json, 잔액 도식.

“Privacy는 고정한 Clairveil 커밋의 로컬 체인에서 실행했습니다. Alice가 10 uclair를 예치하고 Bob에게 7을 보내면 각 지갑에서 Alice의 잔액 3, Bob의 잔액 7을 확인합니다. 준비용 self batch와 최종 지급의 블록에 기록된 결과의 code가 0인지 확인했고, 계정과 체인 상태를 새로 만들어 다시 실행했습니다. uclair는 로컬 자산이며 OKRW가 아닙니다. Maroo용 호환 아티팩트와 조회·증명 연결을 확보하지 못해 로컬 결과를 Maroo 성공으로 주장하지 않습니다. 감사자 복호화와 운영용 키 관리도 별도입니다.”

## 4:55–5:55 / 워크숍과 장애 대응

화면: 70분 시간표, Troubleshooting.

“설명과 실습을 구분했습니다. 앞부분은 지급 역할과 PCL/EAS를 이해하고 실제 정상·거절을 실행합니다. 뒤에서는 별도 로컬 Privacy 흐름을 수행합니다. 설치와 회로 생성은 사전 준비입니다. RPC나 환경 문제에 3분 이상 막히면 실제 저장 증거 분석으로 전환하고, 참가자의 직접 실행 성공으로 세지 않습니다. 전체 진행 시간은 아직 측정하지 않았습니다.”

## 5:55–7:00 / DX와 AI 검증

화면: SUBMISSION_NOTES의 DX·AI, Explorer Raw/Decoded.

“실제 차단 거래의 Explorer에서는 오류가 깨진 문자로 보였습니다. ABI로 해석하면 InDenylist와 해당 주소였습니다. 그래서 읽을 수 있는 오류 설명과 원본 hex를 함께 제공하는 개선안을 작성했습니다. EAS 발급 후 인덱싱을 확인하는 절차도 문서에 보완할 지점입니다. AI는 실행 래퍼와 자료 제작을 가속했지만 placeholder를 실제 조회로 안내하거나 simulation 체험을 실제 인증으로 오해한 오류가 있었습니다. 사용자 출력과 거래 증거로 수정했습니다. 이번 제출은 기능을 많이 나열하기보다 무엇이 실행됐고 어떤 경계가 남았는지 보여주는 데 집중했습니다.”

촬영 시 .env, 원시 로컬 지갑 로그, 브라우저 인증·개인정보 화면은 열지 않습니다. 실제 녹화 시간을 확인하고 5–8분을 벗어나면 편집합니다.
